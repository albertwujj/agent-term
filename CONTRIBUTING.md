# Contributing to AgentTerm

AgentTerm [runs from source](docs/dev/install.md). Each new window picks up the current code from that checkout. See the [repository instructions](CLAUDE.md) and [development guide](docs/dev/development.md).

Before submitting a code change:

1. Pass the [build and all tests](docs/dev/development.md#builds-and-tests), including E2E tests.
2. Open a new window from the changed checkout and confirm the improvement in actual use.

Include what you tried and what improved in your pull request.
