# Essays — Rethink what a terminal should be for AI CLIs

I use AI CLIs for coding, writing and planning, and that changes what I want from a terminal. Each essay explores one design decision behind AgentTerm, based on more than eight months of daily use.

1. [Why I give each agent its own OS window and a distinct Dock tile or taskbar button](own-os-window.md)
2. [Why I run my own terminal from source](run-from-source.md)

Planned so far:

- Why I put docs, code and other file contents within the terminal window over separate apps
- Why I sometimes comment directly on terminal output, and sometimes continue with the agent in a document
- Why I review an agent's curated walkthrough over the full diff
- Why I make my agents share one checkout over separate worktrees
- Why AgentTerm builds on the terminal's plain text over integrations and plugins
- Why AgentTerm uses a folder hierarchy of Markdown guides instead of skills
- Why I use coding agents for writing and how I use my expanded terminal to do it
- Why I tell my transcription service to skip auto-correction
